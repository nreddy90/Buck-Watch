From idea to hackathon demo.

A focused 36-hour roadmap for the full Buck Watch stack.

The architecture

React + TypeScript website → Spring Boot API → PostgreSQL. Spring Boot calls a Python FastAPI forecasting service and the OpenAI Java SDK. Keep calculations in deterministic backend code; use the LLM to interpret scenarios and explain results.

The demo story

Load six months of synthetic transactions. Explain the baseline. Ask “What if I move and rent goes up $500?” Compare trajectories, then add a $2,000 laptop purchase. Show which assumptions changed, how much money remains, and the ML forecast uncertainty. Finish by showing the architecture and evaluation results.
